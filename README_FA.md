# رمز سزار

[English guide](README.md)

با جابه‌جا کردن حروف انگلیسی در الفبا، یک پیام را رمزگذاری یا رمزگشایی کنید. این تمرین برای کار با رشته‌ها و عملگر باقی‌مانده است.

## نصب سریع در اوبونتو

دستور زیر را در ترمینال اجرا کنید. به `curl` و پایتون ۳٫۸ یا جدیدتر نیاز دارید.

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/seetaayeesh/caesar-cipher/main/install.sh | bash'
```

بعد از نصب، برنامه را با این دستور اجرا کنید.

```bash
~/.local/bin/caesar-cipher
```

نصب در پوشهٔ خانگی شما انجام می‌شود. برای به‌روزرسانی، همان دستور نصب را دوباره اجرا کنید. اگر ابزارهای لازم را ندارید، ابتدا `sudo apt update && sudo apt install curl python3` را اجرا کنید.

## اجرا

به پایتون ۳٫۸ یا جدیدتر نیاز دارید. در ویندوز، از پوشهٔ همین پروژه دستور زیر را اجرا کنید.

```powershell
py main.py
```

در لینوکس یا مک از `python3 main.py` استفاده کنید. برنامه به نصب بستهٔ اضافی نیاز ندارد.

## نمونه

برای رمزگذاری گزینهٔ `1` و برای رمزگشایی گزینهٔ `2` را بزنید. سپس پیام و مقدار جابه‌جایی را به‌صورت عدد صحیح وارد کنید.

```text
Choose 1 or 2: 1
Message: XyZ! 42
Shift: 3
Encoded message: AbC! 42
```

برای برگرداندن پیام، گزینهٔ `2` را بزنید و متن `AbC! 42` را با همان جابه‌جایی ۳ وارد کنید.

## کد چگونه کار می‌کند؟

برنامه حروف انگلیسی را جابه‌جا می‌کند و بزرگی یا کوچکی آن‌ها را حفظ می‌کند. فاصله‌ها، رقم‌ها، نشانه‌ها و حروف فارسی به همان شکل باقی می‌مانند. عملگر `% 26` جابه‌جایی را در محدودهٔ الفبا نگه می‌دارد. رمزگشایی با همان تابع و جابه‌جایی در جهت معکوس انجام می‌شود.
